How to Enable Built-in AI in Google Chrome

Setup Guide

If your background is Magenta, Google Chrome's on-device Gemini Nano model is either not enabled or needs to be downloaded. Follow these steps to turn it Green:

1

Use Chrome 128+ or Chrome Dev / Canary

Built-in AI APIs require modern Chrome with on-device AI capabilities enabled.

2

Enable Gemini Nano Chrome Flags

Paste each URL below into your Chrome address bar, set to Enabled, and relaunch Chrome:

chrome://flags/#prompt-api-for-gemini-nano
chrome://flags/#optimization-guide-on-device-model
chrome://flags/#rewriter-api-for-gemini-nano
3

Verify Optimization Guide Component

Visit chrome://components, find Optimization Guide On Device Model, and click Check for update to download the Gemini Nano weights.
